Science content review

Every authored question, with its marked answer and explanation.

The maths questions are checked by a script against their own answer keys. Authored science items cannot be checked that way: a wrong fact would pass every test. This page lists all of them so they can be read, rather than found by clicking through quizzes.

  • Each slot is one question position in the exercise. A student sees one item from each slot per visit; "Try one like it" gives another item from the same slot.
  • Items marked generated have fresh numbers every time, so three samples are shown.
  • For multiple choice, every option is listed, so the distractors can be checked too. For sorting, the whole bank is listed; a student sees six.
  • Each item has an ID such as 7.1·Q4·3, so a problem can be reported precisely.
  • Items and cards added or changed since the last approved review are marked new.
